# Independent formula children, candidate 1

This is a new, isolated, paper-first diagnostic. H5/H6 were consumed by the
failed blind batch and are now seen pages. No new holdout is opened. Predecessor
engines, thresholds, reports, and artifacts remain frozen.

## Problem and bounded change

A flattened display-math image includes the original blank horizontal distance
to its equation number. Fitting that whole image to a narrow column shrinks the
mathematical core unnecessarily. A detached number can also appear as an
unrelated paragraph. Represent independently owned core and number units as
children of a formula block. Never split a native unit or slice a screenshot.

Only a native closed region proposed as formula by the optional layout prior,
with independent geometric formula evidence, may be a core. A short mapped
numeric candidate is only weak label evidence. Native Unicode mapping is NOT
semantic certification. The earlier localgeometry trace key
`certified_numeric_label_only` overstated this and is not reused here.

Association also requires: same region-tree column; one unique core/candidate
relation; candidate to the right of the core within the region bounds; matching
an observed core baseline row; an empty spatial corridor; a closed visible
native-index interval; bounded gap relative to the column, height and area;
and exactly two independently owned native units. These checks are typed
configuration and produce reasons. Already indivisible formulas with a number
inside them abstain. A model box never supplies the content or serves as GT.

## Layout

Retain each child's original native image/vector, paint order within that child,
relative glyph geometry, scale isotropically, and preserve core-then-number
logical order. If both fit at the requested size, put the number to the right.
Otherwise fit the core alone to available width and put the number in a right
aligned following row at requested body size. No formula-internal line breaking.
Source whitespace between independent children may change; ink cannot.

## Pre-registered checks and failure definitions

- Authored controls: ordinary numbered display; multiline core; missing label;
  unreliable mapping; nearby citation/prose; intervening native-index glyph;
  corridor intrusion; competing cores; cross-column number; bounded-width
  rejection; indivisible group. Accepted relations must be unique and continuous.
- Ownership: output native-unit multiset identical; no unit split. If unpacking
  an old composite, its target-grid RGBA must be exactly reproduced by child
  supports in original coordinates, with no overlap or fractional-alpha shortcut.
  Failure rejects conversion. This is a source composition check, not proof that
  every source paint was captured originally.
- Moved layout: each child has one placement, positive uniform scale, preserved
  image extent and native geometry, no overlap/viewport clipping. Native images
  must be sampled at least at actual requested scale times DPR. Test 20px/DPR1
  and 28px/DPR2 at 390px; same-size integer-device translation must retain exact
  isolated-child raster content. Fractional-phase antialiasing differences are
  recorded separately and cannot conceal structural clipping.
- Reading: visually review full seen-page output at both sizes against the
  source, including math strokes, equation number association and neighboring
  paragraph order. Any observed omitted/duplicated ink, bad order, unintelligible
  display formula or unassociated number is a reading failure, regardless of
  index conservation. Do not certify Unicode/copy, browser interaction, theme,
  full zoom or whole cold page performance from this cached diagnostic.
- Report exact bytes/resources and cached-stage timings. Prior full cold-page
  60-second failures remain. No page-budget pass without a new complete cold run.
