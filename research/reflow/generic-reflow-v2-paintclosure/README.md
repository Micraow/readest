# Bounded printed-paint closure and native batches

Isolated follow-on to the immutable native-ownership checkpoint. `closure_config.py` contains geometry/character bounds. Source labels, paper identity, named fonts and literal formula terms do not select rules.

`close_paint_units.py` iterates contained native paint/text and logical intervals around existing graphic hypotheses. Apparent background fills enclosed by a figure are local paint regardless of color. Bounded width/height/area, character count and seed-expansion guards reject page-sized closure. Native object records with no observed ink remain in the ledger but cannot inflate visible geometry at the tested grid.

`support_interactions.py` checks actual owned native alpha support across units. `close_support_intervals.py` closes bounded continuous intervals when contact exists. Merely counting identifiers or matching aggregate pixel counts is insufficient; source-order native compositing remains a separate test.

`render_native_batches.py` renders a unit's selected native objects in original order when every text object is internally owned. Shared text objects use the earlier action-mask native replay so foreign glyphs cannot leak into an asset. It refuses a mismatched mask grid, changed native activation state, unsupported compositing or local source-support mismatch. The internal native page bitmap is not a full-page reading output.

D4's incomplete figure, loose superscript overmerge, and bad global y-order reader are retained privately. Better local paint fidelity did not by itself make a readable paper. See the separate `generic-reflow-v2-order-tree` layer for hierarchy, actual whole-page visual review, costs, and remaining failures. No new annotation-specific work is included after the user's paper-priority scope revision.
