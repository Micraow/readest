# Integrated paper diagnostic 1

This composition combines already isolated localgeometry, native baseline
normalization, indexed native-origin bridge and formula hierarchy. Direct prior
execution is included only after its separate authored-operator and fresh model
A-B-B-A equivalence comparisons all pass. No new document is opened.

H5 then H6 are run from their existing local PDF bytes, with a fresh output,
fresh model process, native inventory, source composition proof, native glyph
capture, bridge, target-grid images, layout and first 390px 28px/DPR2 native
canvas render plus private HTML generation. No cached plan, model prediction,
glyph paths or image resources are supplied. OS file cache is not flushed.
No source preprocessing is excluded from the request. The initial canvas render
writes diagnostic images as part of measured cost; this is not a browser test.

The previously tested supervisor pins both itself and all children to one CPU,
reaps killed descendant processes and reports their CPU plus its own CPU. A
request exceeding 60 seconds or 1 GiB sampled family RSS is killed and fails.
Prior partial results may be inspected but cannot be silently resumed into a
successful budget result. All phase costs, load and failure evidence are kept.

All source replay/support/native-unit gates must pass. These are necessary,
not sufficient: a completed request still needs full 20/28px visual inspection,
formula/reading-order checks and disclosure of browser, selection/copy, theme
and local zoom limitations. Native-unit conservation never certifies pixels.
The original blind result remains 0/2. H5/H6 are permanently seen diagnostic
pages; this composition cannot retroactively turn them into blind passes.

The previous whole cold requests failed at about 60.1 seconds. Differences in
shared machine load mean an observed speedup is not assigned to a mechanism
from a single page run; the paired direct-prior and bridge experiments supply
separate stage evidence. A completed page under budget is one observation,
not a universal performance guarantee.
