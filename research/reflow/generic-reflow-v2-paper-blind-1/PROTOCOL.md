## Gates and predeclared failure classes

- ACQUISITION: pinned archive/entry/bytes mismatch or unavailable. No substitute source.
- EXECUTION: stage exception/nonzero exit. Preserve the exception and current stage.
- BUDGET_WALL / BUDGET_MEMORY: whole request exceeds the above envelope.
- OWNERSHIP: native source replay not exact, any source-support failed unit, or duplicate/missing unit in the native reader. Reject accepted reader, even if an intermediate HTML exists.
- OBSERVER: instrumented glyph capture changes original rendering. Unsupported native glyphs may use the existing bounded local-image route; no guessed Unicode redraw.
- TARGET_GRID: any requested fallback asset rejected, wrong scale/backdrop or overlapping support.
- ORDER: unresolved region tree or visual reading-order error (column interleaving, detached captions, misplaced cross-column continuation, prose/heading merged incorrectly).
- CONTENT: visible missing/duplicate printed text, formula symbol, rule, graph label or image content; an ID bijection alone does not pass this gate.
- GEOMETRY: script/base separation, altered fraction/diagram relative geometry, clipping, or overlapping unrelated output tokens. A retained source-line hyphen is a separate known readability defect, not silently deleted text.
- READABILITY: complete-page source-to-output review at both sizes finds unnatural paragraph breaks, broken mathematical grouping, collapsed spacing or incorrect region flow. Report each actual observation. No readability pass from summary counters alone.
- UNSUPPORTED: safe refusal required by current contracts. No whole-page reader-image fallback.

Accepted research reading result requires structural/source gates and complete visual checks. Strict anti-aliasing/pixel differences remain reported separately from structural errors; no new tolerance is invented after viewing the samples. Native word selection/copy, arbitrary dark backgrounds, browser interaction and production/mobile integration are already unimplemented or unverified and cannot pass this batch. Local zoom interaction remains untested. Full universal paper acceptance therefore cannot be claimed even if the limited reading checks pass.
