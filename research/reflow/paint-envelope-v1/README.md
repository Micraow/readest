# Painted extent invariant: frozen mechanism test

The logical glyph rectangle is not the painted-ink rectangle. This module enumerates actual text/path/image/shade paint envelopes, applies page rotation and scale, subtracts the real pixmap origin, and rounds outward with a uniform one-pixel raster support. Any visible source ink not explained by these envelopes forces original-page fallback. It does not delete residuals or adjust a paper-specific margin.

A single frozen pass tested eight original fixtures at 1.25x and 4x, plus the previously seen GroupNorm page as mechanism regression. All 17 rendered cases had zero ink outside the physical envelopes and zero changed RGB pixels in the ownership reconstruction. The two previously diagnosed radical-tip pixels are within the text-paint coverage. Visual QA found that the original Symbol-font insertion rendered a dot instead of the intended radical, so those fixtures do not establish radical handling. A separately logged fixture correction uses TextWriter to emit a verified radical, then tests the unchanged envelope algorithm at both scales; both additional cases have zero residual ink. The source glyph was corrected, not the coverage rules. The original results remain unchanged. The synthetic cases exercise italic bearings, transformed text, heavy stroked text, clipped Forms, CropBox offsets, 90-degree rotation, colored transparency and a visible annotation. In this PyMuPDF version the annotation was represented in the paint log, so no annotation fallback was required.

The 17-case pass took 1.70 seconds in the instrumented run, with 256,696 KiB peak RSS. The real-paper case took 0.59 seconds. This is coverage at original source resolution, not a reflow or semantic result. GroupNorm remains a seen diagnostic. Fixed one-pixel support is an engineering raster envelope validated only by these cases, not a universal proof for every renderer. The residual guard remains necessary for unsupported paint types, clipping/transform cases or renderer differences.

Paint rectangles can overlap and can encompass several logical lines. Their coverage cannot tell which formula owns a number, define a paragraph, or certify reading order. Subsequent composition must keep physical containment and semantic association as separate evidence. No formula content was regenerated, and no prior frozen experiment was modified.

Reproduce with Python, PyMuPDF 1.26.6 and NumPy. `code/run.py` generates the original synthetic fixture PDF locally and expects the existing public-paper diagnostic at its recorded relative location. Paper PDF bytes and rasters are omitted from this public checkpoint. `RESULT.json` contains only aggregate measurements; detailed paint coordinates and paper evidence remain local. The source/configuration hashes in `CODE-FREEZE.json` precede the one run. No app integration or Android tests were performed.

Official API contract: [PyMuPDF get_bboxlog](https://pymupdf.readthedocs.io/en/latest/functions.html#Page.get_bboxlog) describes rectangles enveloping text, drawing and image objects. These are drawing bounds, not semantic labels.
