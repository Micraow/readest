# H8 seen atomic-region diagnostic: structural progress, visual refusal retained

This is an opt-in investigation after the recorded blind failure. The first H8
request remains **0/1 in 17.73 seconds**. No default cold pipeline, generic
safe-cut threshold, holdout denominator or original result was changed.

## What is implemented

A local native region may remain indivisible instead of inventing a semantic
order among adjacent graphics. Its source leaves, native character membership
and source units remain bijective. The unchanged safe-cut tree must place it
relative to the remaining page, and native intervals must remain monotone even
when an intervening graphic has no character index.

Text enters only under a high-confidence independent image prior, dominant
native graphic support and a shallow internal strip bracketed by graphic rows.
Independent body/caption/footnote evidence vetoes grouping. Boundary-crossing
leaves, external source intervals, sparse graphical frames, oversized regions,
duplicate ownership and unresolved order fail closed. These experimental bounds
are additional refusals, not relaxations of existing default thresholds.

On this seen page, one region retains ten native images and two internal label
leaves at their original positions: 12 original leaves / 29 source units. Its
box-level graphic coverage is 83.31%; independently rendered graphic support
actually occupies 83.78% (278,879 of 332,869 native pixels). The image prior does
not include the lower label row. It is deliberately not extended by guessing.

## Visual result and remaining boundary

The complete 28 px / 390 px output was inspected against the actual source page.
Reading acceptance remains **false**: lower panel labels are detached into five
paragraphs, a two-line section heading remains split, uncertain printed line-end
hyphens remain in reflowed words, and wide figures become small on mobile widths.
The original PDF remains the trustworthy fallback. No semantic label order,
hyphen deletion, larger grouping box or successful browser test is inferred.

Controls include 38 atomic-region checks and five intentional conservation
mutations, plus the existing mapping, selection, interaction and layout suites.
See the JSON report for counts and per-grid evidence. Real browser mouse selection,
clipboard behavior, browser composition and the full Readest app build remain
unverified.

## Reproduction and distribution

Use the official source acquisition helper and original model/plan stages, then
run `prepare_atomic_diagnostic.py PDF NATIVE OUT --image-priors` with an external
60-second cap. Only its verified plan may feed the existing
`continue_verified_reader.py ROOT PDF PLAN ORDER CACHED_MODEL OUT`, separately
bounded. Run `audit_atomic_reader.py READER ORIGINAL_PLAN OUTPUT_JSON`, the
private-fixture mutation controls, and `render_atomic_gates.mjs RUNTIME READER_JSON OUT`.
The audit compares the reader plan to the original plan, rather than trusting a
self-consistent modified plan. All counts and proof hashes are non-content data.

Only source code, official acquisition metadata and non-content results are
public or allowlisted in the standalone handoff. H8 paper bytes, extracted text,
glyphs, contour resources, rendered images and populated viewer bundles remain
private and are excluded from those artifacts.
