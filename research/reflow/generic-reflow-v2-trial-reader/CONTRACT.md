# Private precomputed two-page trial, not an arbitrary-PDF product

The already reviewed formula-hierarchy payloads and shared painter stay unchanged.
Package private page payloads, the corresponding original PDFs and native source
reference images into one self-contained local HTML. No network request, model,
new extraction, or public paper upload occurs in this packaging step.

Provide page/font choice and a per-paragraph return-to-source action. The source
view highlights original token rectangles over the original native reference,
then optionally shows original page context or opens the original PDF. This is a
user-invoked reference view, never the main reading output or a whole-page fallback.
Validate all source boxes against the source capture scale/page dimensions.
Local image focus displays the existing target-grid asset at native samples only;
it must not promise arbitrary lossless enlargement. Selection is visibly marked
unsupported until a reliable, independently checked semantic layer exists.

Do not call precomputed asset loading a cold page pass. H6 still times out in its
complete request. Original blind results remain 0/2; source hyphens, title splitting,
unknown mathematical Unicode and lack of real-browser interaction QA remain.
The preview is private and unintegrated with Readest. No full-text content or
font resources are committed publicly. A local native-renderer equivalence check
and JS syntax check are not a browser pass. The next useful milestone is reliable
ordinary-text selection plus bounded source return, tested in one original-only
browser fixture batch rather than further serial single-page timing tweaks.

Experimental mapped previews may expose native keyboard buttons for paragraph
selection and local image focus. Announce copy refusal in a live status region.
Source-dialog close/Escape must release its content and return focus to a connected
trigger (or font selector if layout replacement removed it). Discard delayed views
from a superseded page. Simulated DOM lifecycle checks are not browser evidence.
