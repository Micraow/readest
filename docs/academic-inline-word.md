# 学术行内图形与相邻文字的换行

## 已复现的问题

既有原生版本在宽窗口、16 号字下，会把短求和式的求和符号留在行末，
操作数及下标单独排到下一行。符号是原 PDF 裁切按钮，操作数是可选择文字，
两者虽无空白相隔，独立的 inline-block 按钮仍提供了额外断行机会。
这会打断短式阅读；不是字符丢失或公式顺序变更。
527 像素窗口下的 16、22 号字在该位置恰好能整式排下，不能声称每个宽度均复现。

## 局部处理

仅在 InlineContent 呈现层，合并含图形按钮的连续无空白词形片段，
采用有最大宽度限制的 inline-block。原有空格保留，普通正文仍按原方式换行。
图形自己的替代文本保持原子性，其内部空格不能把图形切开。

外层不使用 nowrap、裁切或固定行高。过长的词形在窄容器内仍可自然换行。
引用边界分别渲染，图形缩放按钮不会被嵌进引用链接。
原文字符顺序、样式、裁切几何、缩放参数、parser 和 academic-13 缓存均不改变。
