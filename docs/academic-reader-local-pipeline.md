# 本地结构化论文重排

PDF 的布局分析、阅读顺序、图表归属、重排与区域渲染全部在本地完成。
这条流程不包含云端解析、PDF 上传、远程增强接口或服务选择器。
Zotero 的已授权只读文件下载属于输入获取，不参与 PDF 重排计算。

## 统一的数据边界

`PDF.js → PageGeometry → ScholarlyDocument → ScholarlyReader`

- `PageGeometry` 保存原文文本项、字体信息、图形范围和规范化源坐标
- `ScholarlyDocument` 保存段落、标题、列表和保留原布局的视觉块，以及阅读顺序和源映射
- 视觉块的 `captions` 显式保存图表类型、编号、图注文本及对应源范围；这些是关联，不会重复占有原文项
- 正文、列表和图注的 `inlineRuns` 保存可选择的样式文字或局部原文公式；每个片段都保留源坐标，不能把二维公式压成随意的字符顺序
- 渲染层消费这些结构，不根据画布位置重新猜测图号、图注归属或正文顺序

## 正文与视觉块分开处理

正文先恢复跨页、跨栏的连续段落，不能让页顶浮动图把同一句分开。
只有段落边界、字体与列边界支持时才合并；标题、列表、公式和未知保留区域构成边界。
页顶或栏顶浮动算法也要让跨页、跨栏的完整句先接续，同栏算法仍保留其段落边界。
换行开头的解释性破折号不能自动变成项目符号，真正的连续列表则保留其结构。
等号后换行的数字值保留在正文中，避免误认成编号列表。

页眉先结合跨页重复、稳定的首行位置、字号和间隔识别，再重建正文流。
紧邻图形的共享图例和具有正常行距的正文不能作为页眉删除。
已经识别的脚注、首页投稿及作者说明保留为独立注释块；跨栏续句先连完整，
再显示注释，不把注释文字混入正文。

图注识别独立于正文的栏数。一行中两个并排图注可以具有两个不同的语义身份，
即使正文只有一栏。独立图使用各自的局部视觉范围；如果两图共用跨越中线的图例，
保留完整组合图，并保存双方的图注关联，不能为了拆图号切掉共享标签。
下方正文仍属于可重排文字，不能因为路径连通或裁图留白而被收入图片。

图表保留原文中的先后，只在它打断跨页、跨栏段落时先把段落接完整。
不能为了追随首次正文引用而远距离搬动图表；这会颠倒作者安排的图序。
同排图注确定相邻图的从左到右顺序，不按图高或讨论顺序重排。
可靠的底部图注作为独立文字显示，预览只包含图区；放大仍显示完整源范围。
小图按原文与正文字号的比例显示，相邻小图在宽窗口中并排，在窄窗口中自然换行。
展示公式与算法保留原布局和放大能力。
被浮动图或注释延后的展示公式，仍须紧邻以冒号结尾且位置相邻的引导段落。
正文的字号判断优先使用正文文字片段，不能让分子、分母和下标的小字号把同段正文拆开。

行内分式由实际分数横线及其上下文字范围识别，横线可以来自路径或细图片。
分式保持局部原文图像和基线位置，周围正文仍可选择。相邻两行下标的垂直重叠
不能单独证明它们是一条分式；缺乏可靠几何证据时不猜测二维结构。
明确的字体信息恢复粗体和斜体，短小且基线偏移明确的字形保留上下标。
分式按分数线旁的正文基线插入，不能按最早出现的分子文本行决定位置。
对紧贴下一原文行的局部分式，仅在实际像素中找到所选字形最低基线之后的完整空白带时，
清除该空白带下方的邻行碎墨；找不到可靠分隔时保留原图，不能硬切字形。

## 缓存与渐进工作

提取/分析在 worker 中运行，按页报告进度，并在渲染层按可见范围延迟生成图像。
缓存键包含完整文件指纹、结构版本和解析器版本。布局算法改变时增加解析器版本，
保留旧缓存文件但不复用其分析结果。缓存重开需同时验证结构、源项所有权和图注关联。
每个行内片段也单独验证原文项覆盖，避免段落拥有全部原文、实际显示却遗漏部分公式。

## 验收

源项覆盖只是必要条件，不证明阅读质量。还需验证：

- 不串栏、跨页连续句不被图隔开、列表没有被吞并
- 图号与原始图像一致，完整图注和共享图例均保留
- 图像范围不吞正文、局部图像不会扩大成整页
- 单栏与双栏文档、图表、算法、公式都使用同一数据契约
- Linux 原生窗口中的重排、放大返回、窄窗显示和缓存重开

无法可靠识别的无横线堆叠符号、特殊字体及复杂排版仍可能不完整；原 PDF 视图
保留原始表达。当前实现不宣称重建所有排版语义，后续改进仍以结构反例和实际像素验收。
