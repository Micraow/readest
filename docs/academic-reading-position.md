# 学术阅读位置：字符锚点

这次改动只涉及阅读界面的定位。PDF 解析、段落归属、公式裁切、分析缓存及
`academic-13` 解析版本均不变化。

## 原因与行为

旧实现为重新打开保存 `scrollTop`，为字号变化保存整块顶部的像素偏移。
当一块含有多行参考文献，或窗口宽度使前面的文字重新换行时，旧像素位置会落到另一行。

现在记录稳定块 ID、跨样式文本节点的字符偏移及这个字符相对视口的高度。
字号变化、窗口变化和晚到的图片尺寸完成后，重新定位同一字符。
图片区域使用块内比例作为兜底，图注进入视口后可使用文字锚。

同一字符锚必须跨连续重排保留：新行可能从它之前的字符开始，不能每次恢复后
改存新行首。只有真实滚动或明确的引用/脚注导航才重新记录当前位置。
引用跳转和返回会同步通知位置状态，避免延迟尺寸事件覆盖较新的导航。

本地位置记录保留旧数值 `scrollTop` 的读取兼容；新记录包含字符锚和像素兜底。
无效记录或不存在的块不会阻止阅读。关闭时会保存尚未派发 scroll 事件的新位置。

## 检查范围

- 长块字号变化前后保持同一字符
- 多样式文本、行内公式错误占位不改变字符计数
- 连续窄宽往返，不累计逐行倒退
- 字号重排之后才完成图片尺寸，仍保留字符位置
- 在不同宽度关闭、重新打开，保留原字符锚
- 待处理尺寸变化期间的新引用导航优先
- 图片比例兜底、无效位置记录、旧数值兼容和监听清理

确定性行布局的单测用于证明状态与顺序，不代替真实浏览器换行。
提交前 320 项学术/图像查看器测试、应用 TypeScript 和 Biome lint 已通过。
新的 Linux 原生大字号、窄窗和往返重开验收必须对本次新构建进行。
完整仓库测试及新构建验收结果需在执行完毕后另补，不把旧包验收记到新包上。

系统主题方面，已有 `matchMedia`、可见性监听及数学样式订阅，本次不增加第二套监听。
